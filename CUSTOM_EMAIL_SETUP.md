# Custom Email Template Configuration Guide

## Overview
timenow.sbs uses a custom HTML email template for email confirmations. This guide explains how to configure it in Supabase.

## Email Template Features

The custom confirmation email includes:
- ✓ **timenow.sbs branding** with logo and gradient header
- ✓ **Welcome message** introducing the platform
- ✓ **Feature highlights** showcasing key benefits
- ✓ **Clear CTA button** for email confirmation
- ✓ **Alternative link** for email clients that don't render buttons
- ✓ **Security information** explaining link expiration and safety
- ✓ **Social media links** to Twitter, GitHub, LinkedIn
- ✓ **Footer** with privacy and legal links
- ✓ **Professional styling** with proper spacing and typography

## Template Location

The email template is available at:
```
/lib/email-template.ts
```

Functions:
- `generateConfirmationEmail(email, confirmationUrl)` - Signup confirmation email
- `generateWelcomeEmail(email, firstName)` - Post-confirmation welcome email

## Step 1: Configure in Supabase

### Access Email Templates:

1. Go to your **Supabase Dashboard**
2. Navigate to **Authentication → Email Templates**
3. Find **Confirm signup** template
4. Click **Edit**

### Replace with Custom Template:

Option A: **HTML Template (Recommended)**
- Copy the HTML from email template
- Paste into Supabase email editor
- Replace variables with Supabase placeholders

Option B: **Use Supabase's HTML Editor**
1. Click "Show HTML"
2. Paste the HTML template
3. Update variable placeholders to match Supabase format

### Supabase Variable Placeholders:

Replace template variables with these Supabase placeholders:
- `{{ .Email }}` - User's email address
- `{{ .ConfirmationURL }}` - Confirmation link (auto-generated)
- `{{ .Token }}` - Confirmation token

## Step 2: Configure Custom Subject Line

1. In Email Templates editor
2. Find **Subject** field
3. Set to: `Confirm your email on timenow.sbs`

## Step 3: Enable Custom Redirect

After email confirmation, redirect users to success page:

1. Navigate to **Authentication → URL Configuration**
2. Set **Redirect URLs**:
   - `http://localhost:3000/auth/sign-up-success` (Development)
   - `https://yourdomain.com/auth/sign-up-success` (Production)

## Step 4: Test Email Delivery

### Test Signup Process:

1. Visit `/auth/sign-up`
2. Enter test email and password
3. Check email inbox (or spam folder)
4. Verify:
   - Email subject is correct
   - Email styling displays properly
   - Confirmation link works
   - Clicking link confirms account

### Test Email Rendering:

- Test in multiple email clients:
  - Gmail
  - Outlook
  - Apple Mail
  - Mobile (iOS Mail, Gmail app)

## Email Variables Guide

| Variable | Purpose | Example |
|----------|---------|---------|
| User Email | Recipient email address | `user@example.com` |
| Confirmation URL | Link to confirm email | `https://timenow.sbs/auth/callback?...` |
| Token | Security token | Auto-generated by Supabase |

## Troubleshooting

### Email not received
- Check spam folder
- Verify email is in Supabase allowed list
- Check SMTP settings in Supabase
- Verify email is confirmed in Supabase project

### Template styling broken
- Test in Supabase email preview
- Check all CSS is inline
- Verify image URLs are absolute
- Test across email clients

### Links not working
- Verify confirmation URL is properly formatted
- Check redirect URLs in Supabase
- Ensure domain matches production URL
- Test with unsubscribe link format
